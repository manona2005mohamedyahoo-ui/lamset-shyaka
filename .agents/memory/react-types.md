---
name: توافق أنواع React
description: تعارض أنواع المراجع بين حزم الويب وExpo بعد تحديث الاعتمادات.
---

راجعي نسخة تعريفات React المشتركة عند تحديث اعتماد ويب في هذا المشروع الذي يجمع Expo والويب.

**Why:** قد يُحدَّث نطاق الأنواع في الويب إلى إصدار أحدث بينما يحتفظ Expo بإصدار فرعي أقدم؛ ينتج عن ذلك نوعان غير متوافقين لـ Ref رغم تطابق اسميهما.

**How to apply:** وحّدي التعريفات على إصدار يطابق قيود التطبيقات، ولا تعالجي التعارض بإخفاء أخطاء الأنواع أو تحويل المراجع إلى any. تحققي من وجود إصدار react-dom المطلوب بدل افتراض أن ترقيمه يطابق react.
