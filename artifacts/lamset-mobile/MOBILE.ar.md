# تطبيق لمسة شياكة

تطبيق React Native / Expo لأندرويد وآيفون، مرتبط بكتالوج Shopify نفسه عبر الخادم المشترك.

## الوظائف
- واجهة عربية متوافقة مع اتجاه RTL وهوية الموقع.
- تصفح المنتجات المنشورة والبحث والتصفية حسب القسم والتوافر والترتيب بالسعر.
- تفاصيل المنتج وصوره ومتغيراته والكمية ومفضلة وسلة محفوظتان على الجهاز.
- مراجعة السعر والتوافر بإنشاء سلة Shopify فعلية ثم فتح checkoutUrl لإتمام الطلب لدى Shopify.
- مدخل الإدارة يفتح لوحة Shopify الخارجية. Shopify يدير تسجيل دخول المالك والموظفات وصلاحياتهم؛ لا يوجد مفتاح محلي يمنح الإدارة.

## حدود واضحة
- الإدارة ليست شاشات CRUD أصلية داخل التطبيق. لا تُجمع كلمة مرور Shopify داخل التطبيق.
- التصفح كضيفة؛ لا توجد حسابات عملاء أو مزامنة مفضلة بين الأجهزة.
- لا يوجد إرسال واتساب أو تأكيد دفع محلي أو إشعارات أو تتبع طلبات داخل التطبيق.
- لا توجد منتجات تجريبية؛ أخطاء الاتصال لا تُعرض ككتالوج فارغ.
- قد يتطلب Shopify تحديث ربط الخدمة أو نشر المنتجات في قناة البيع.
- فتح صفحة الدفع لا يعني نجاح الدفع أو قبول الطلب.
- دعم النظامين في الكود لا يعني صدور نسخة مثبتة أو نشرًا في متاجر التطبيقات؛ لم يتم إنشاء APK أو IPA ضمن هذا العمل.
- الأصناف التي لها أكثر من 100 متغير تتطلب دعم صفحات إضافية قبل بيع جميع متغيراتها من هذا التطبيق.

## التشغيل والفحص
يشغّل سير العمل `artifacts/lamset-mobile: expo` التطبيق، وسير عمل API Server يشغّل الخادم.
يُضبط `EXPO_PUBLIC_DOMAIN` بواسطة سير العمل لعنوان الخادم. لا تضع مفاتيح Shopify في متغيرات عامة.

```sh
pnpm --filter @workspace/lamset-mobile run typecheck
pnpm --filter @workspace/api-server run typecheck
```

جميع بيانات المتجر والمخزون والأسعار مرجعها Shopify. البيانات المحلية هي فقط اختيارات الزائرة والسلة غير المؤكدة. بيانات التوصيل والدفع تُدخل مباشرة لدى Shopify.
الشحن والضرائب والبوابة والسياسات التجارية تحتاج إعدادًا من صاحبة المتجر قبل البيع.
يجب اختبار صفحة الدفع على المتجر الفعلي والأجهزة الفعلية قبل النشر التجاري.

## ما تم التحقق منه
- اجتاز التطبيق والخادم فحص TypeScript.
- شُغّل Metro والخادم، وظهرت الرئيسية في معاينة بحجم 402 × 874 دون خطأ تشغيل في المتصفح.
- استجاب كتالوج Shopify بالحالة 200 وقائمة فارغة؛ لا توجد منتجات منشورة مرئية للقناة في وقت الفحص.
- نجح الحصول على رابط لوحة إدارة المتجر من إعدادات الاتصال.
- رُفض طلب إتمام سلة فارغة بالحالة 400.
- لم تُختبر عملية شراء أو دخول صاحبة المتجر إلى Shopify، ولم تُختبر نسخة مثبتة على جهاز فعلي.
