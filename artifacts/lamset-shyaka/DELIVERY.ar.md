# لمسة شياكة — تسليم الإصدار الأول

## حدود هذا الإصدار

هذا إصدار أول للواجهة العربية، وليس تسليمًا لجميع مراحل المتجر المطلوبة.
تم ربط خدمة Shopify بالمشروع، لكن ربط الخدمة وحده لا يعني قراءة الكتالوج أو تشغيل الطلبات أو تفعيل الدفع.
لم تُنشأ منتجات أو أسعار أو مخزونات أو تقييمات تجريبية باعتبارها بيانات تجارية.

## التقنية

- React وTypeScript: واجهة منظمة وقابلة للتطوير.
- Vite: تشغيل وتطوير الواجهة.
- Tailwind CSS وأيقونات Lucide: تنسيق متجاوب وأيقونات متناسقة.
- Shopify: الخدمة المختارة لتكون مصدر بيانات المنتجات والمخزون والسلة والطلبات عند استكمال الربط. لا توجد قاعدة منتجات محلية بديلة.

## خريطة الصفحات المقصودة

الرئيسية، التصفح والبحث، أقسام الشنط والعطور والطرح، السلة، المفضلة، الحساب،
نبذة عن المتجر، التواصل، سياسات الشحن والاستبدال والخصوصية، وصفحة حالة إعداد الإدارة.
وجود صفحة حساب أو إدارة في هذه النسخة لا يعني وجود تسجيل دخول أو صلاحيات أو إدارة منتجات فعلية.

## التشغيل

من جذر المشروع، باستخدام Node.js وpnpm:

```sh
pnpm install
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/lamset-shyaka run dev
```

بناء الواجهة محليًا:

```sh
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/lamset-shyaka run build
```

فحص أنواع الواجهة:

```sh
pnpm --filter @workspace/lamset-shyaka run typecheck
```

في بيئة المشروع تُشغّل الواجهة عبر سير العمل المسجّل لها.

## متغيرات البيئة

متغيرا `PORT` و`BASE_PATH` مطلوبان لأوامر Vite.
لا تحتاج الواجهة الحالية إلى أسرار Shopify؛ لا تضع بيانات الاتصال أو مفاتيح الإدارة في متغير يبدأ بـ `VITE_`.
ملف `.env.example` يوضح إعدادات التشغيل العامة فقط.
يُستكمل إعداد اتصال Shopify على الخادم عند تنفيذ الكتالوج؛ لا تُنسخ أسرار الاتصال إلى المتصفح أو المستودع.

## بيانات المنتجات والصور والصلاحيات

لا توجد في هذا الإصدار جداول منتجات أو سياسات قاعدة بيانات محلية أو واجهات تعديل.
عند الاستكمال ستكون Shopify مصدر الحقيقة للمنتجات والمتغيرات والصور والمخزون والطلبات.
الصور التحريرية المعروضة ليست وعدًا بتوفر منتجات بعينها.
لا توجد حاليًا حسابات إدارة داخل التطبيق أو طريقة لتعيين أول مشرف.
يجب تنفيذ تسجيل دخول مُدار، ثم تعيين المشرف من مسار موثوق على الخادم؛ لا تمنح أول مستخدم يسجل تلقائيًا صلاحية الإدارة.
لا يجوز حماية واجهات التعديل بمجرد إخفاء الأزرار في المتصفح.

## الوظائف غير المنفذة بعد

1. استيراد وعرض المنتجات الحقيقية من Shopify وصفحات تفاصيلها.
2. إضافة وتعديل وحذف المنتجات ورفع صور متعددة ومعاينة ما قبل النشر.
3. تسجيل الدخول وصلاحيات لوحة الإدارة وتعديل الهوية والسياسات وبيانات التواصل.
4. سلة فعلية مرتبطة بالمنتجات والمتغيرات والمخزون، وحساب أسعار وخصومات وشحن معتمد من الخادم.
5. مراجعة الطلب وتأكيده، وربط الدفع المستضاف، وتتبع الطلبات.
6. رقم واتساب قابل للتعديل ورسالة الطلب المنظمة. لا يتم إرسال طلب أو فتح رقم افتراضي حاليًا.
7. مساعد وصف اختياري يحافظ على حقائق المنتج.
8. اختبارات CRUD والصلاحيات والشراء وحالات المخزون والأسعار؛ لا يمكن اختبارها قبل تنفيذها.
9. إعداد النسخ الاحتياطي المجدول وتصدير البيانات واختبار الاستعادة.
10. إعداد السياسات التجارية ومناطق الشحن والعملة والضرائب وبيانات التواصل الحقيقية.

## النشر والدومين

يمكن نشر الواجهة للمعاينة، لكنها ليست جاهزة لاستقبال مبيعات.
قبل إطلاق البيع يجب استكمال الربط واختبار دورة الطلب والصلاحيات وتأكيد السياسات.
لا يوجد دومين إنتاجي أو رابط منشور مُثبت في هذا التسليم.
تُضبط إعدادات النشر والدومين من واجهة النشر بعد تحديد النطاق الذي تملكه صاحبة المتجر؛ لا تفترض أسماء DNS أو رابطًا منشورًا.
إعداد بوابة الدفع ومناطق الشحن والضرائب في Shopify يحتاج مراجعة صاحبة المتجر.

## سجل التحقق

- اجتاز فحص TypeScript أثناء بناء الواجهة.
- شُغّل سير عمل الواجهة بنجاح.
- روجع الظهور الأول للصفحة الرئيسية بلقطتي شاشة بعرض 1440 و390 بكسل دون أخطاء ظاهرة في سجل المتصفح.
- لم تُجر اختبارات تفاعلية شاملة أو اختبارات CRUD أو شراء؛ هذه الوظائف غير منفذة في هذا الإصدار.

يُذكر في الرد المصاحب للتسليم ما تم فحصه فعليًا.
فحص الأنواع أو لقطة شاشة لا يُثبت أن عمليات المنتجات أو الطلبات أو الدفع أو واتساب تعمل.
